# Sito personale di Francesco Nunziata

Sito statico in italiano, senza framework o abbonamenti. Destinazione: https://militralian.github.io/.

## Anteprima locale

Da questa cartella: `python3 -m http.server 8080`. Aprire http://localhost:8080.

## Pubblicazione gratuita

1. Usare un repository pubblico chiamato `militralian.github.io` nell'account `militralian`.
2. Caricare il contenuto di questa cartella nella radice del repository.
3. In Settings > Pages, scegliere Deploy from a branch, branch main e cartella /(root).
4. Attendere il completamento della distribuzione Pages.

Non serve un dominio a pagamento. Se il repository esiste già, verificarne il contenuto prima di qualunque modifica. Non sovrascrivere un sito esistente senza autorizzazione.

## Contenuti

`index.html`: contenuto e metadati. `style.css`: grafica e responsive. `script.js`: anno e dettagli espandibili. `privacy.html`: informazioni sul funzionamento del sito. `sitemap.xml` e `robots.txt`: scoperta delle pagine, senza garanzia di indicizzazione.

CV PDF e fotografia non sono inclusi: aggiungerli solo dopo aver ricevuto e approvato i file. Telefono ed email del CV sono pubblicati su esplicita scelta dell’utente, insieme a LinkedIn.
